Changelog

All notable changes to this project will be documented in this file.

[v0.5.2] - 2026-02-10

Added

  • Lightweight C/C++ syntax highlighting in Source Code view (keywords, comments, strings/chars, function-like identifiers).
  • AST search floating popup with per-session query history and completer suggestions.
  • AST compilation warning banner when make-ast reports compile errors.

Changed

  • Renamed Aurora terminology to ACAV across application code, docs, and build files.
  • Added a more robust scripts/run_acav_container.sh helper for runtime/image/workspace/shell options.

Fixed

  • Auto-regenerate stale cached AST files after load failures (without confirmation prompt).
  • Container image resolution now handles both acav:<tag> and localhost/acav:<tag>.

[v0.5.1] - 2026-01-31

Added

  • AST node search with property-qualified filtering (e.g., kind:FunctionDecl name:main), prev/next navigation, match counter, and project file filter.
  • isReferenced property for VarDecl nodes alongside existing isUsed.
  • Human-readable enum labels (valueKindName, objectKindName, initStyleName, storageClassName).

Fixed

  • Collapse All on directories not collapsing header nodes inside source files.

[v0.5.0] - 2026-01-26

Added

  • File path subtitles in Source Code and AST dock title bars.
  • Per-subwindow font size (Ctrl+/- adjusts focused panel only, Ctrl+0 resets).
  • Node Details dialog (right-click → "View Details..." with tree view for all properties).
  • Comment extraction for Decl nodes via ASTContext::getCommentForDecl().
  • Interactive zoom (Ctrl++/Ctrl+-, Ctrl+0 to reset).
  • Reload Configuration menu item.
  • AST placeholder message when no AST is loaded.
  • Lazy header population in TU tree for improved loading performance.
  • Log panel find, copy, clear, and auto-scroll toggle.

Changed

  • Renamed "AST Tree" to "AST" throughout the UI.
  • NodePtr values now display in hexadecimal format.
  • Context-aware Expand/Collapse All in File Explorer.
  • Bundled Clang/LLVM 21, Qt6, and runtime dependencies into container image.
  • Resource directory auto-discovered via clang++ -print-resource-dir.

Fixed

  • Extra blank line at end of source file view.
  • Collapse All Headers bug (headers inside source files not collapsed).
  • stddef.h not found in Docker (added -resource-dir argument).
  • TranslationUnitDecl sync when navigating to nodes without source location.

[v0.4.0] - 2026-01-16

Added

  • Keyboard shortcuts for panel navigation (Ctrl+1 through Ctrl+6).
  • Visual focus indicator on dock title bars.

Changed

  • Macro expansions now show spelling location instead of expansion location.
  • Simplified Open Project dialog (removed misleading placeholders).

Fixed

  • Focus switch lag between panels (replaced setStyleSheet with QPalette).
  • File Explorer sync issues with symlinked paths.
  • Declaration context only shown for Decl nodes; non-Decl nodes show "Not applicable."
  • Clicking declaration context entries now navigates to AST node.
  • HOME/END keys in Source Code view.
  • AST extraction performance (reduced per-node overhead).

Removed

  • Verbose type information option.

[v0.3.1] - 2026-01-13

Changed

  • Support project root and refined file explorer structure.
  • Polish README.

Fixed

  • Potential Windows autoraise issue.
  • Layout issues.
  • Performance issues for expand/collapse descendants.
  • Declaration context view only displays when Decl* node is selected.

[v0.3.0] - 2026-01-12

Added

  • Source Code area supports region selection.
  • Log window for runtime messages.
  • Declaration Context view.
  • Cross-platform Docker run scripts.

Changed

  • Multiple UI improvements.
  • File Explorer-style view for source files and included headers.

Fixed

  • Synchronization between File Explorer View, Source Code View and AST View
  • GUI windows freezing issues

Removed

  • AST node filter

[v0.2.0] - 2026-01-06

Changed

  • Merged programs into the Docker image (based on v0.1.1).

    • Created a v0.1.1 folder with updated binaries.

Fixed

  • Added user feedback on the GUI status bar.
